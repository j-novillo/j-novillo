### What I Apply Day to Day
- **Reactive programming** with Spring WebFlux and **REST API** design (contracts, error handling and versioning).
- **Hexagonal architecture** and microservices, migrating legacy code to reactive services.
- **Resilience** in distributed systems: timeouts, retries and circuit breakers with Resilience4j.
- **Asynchronous messaging** with RabbitMQ (fire-and-forget pattern for heavy processes).
- **Persistence** with JPA, Oracle SQL, MySQL and MongoDB (relational and NoSQL).
- **Unit and integration testing** with JUnit and Mockito.
- **Deployment and CI/CD** with OpenShift and GitHub Actions; observability with Kibana.
- **Best practices:** SOLID, Clean Code, Design Patterns; quality and security with SonarQube and Fortify.
- **Methodology:** Scrum with Jira, in a team of 11.
